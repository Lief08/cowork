# Architecture

This directory contains architectural decisions, system designs, and technical strategy documents.

## Contents

- **ADRs/** – Architecture Decision Records (use `templates/adr.md` to create new ones)
- Design documents and diagrams
- Technical strategy notes

## When to add something here

- You've made a significant design decision that future work should reference
- You're designing a system or component and want to document the approach
- You want to capture trade-offs considered and the rationale for choices made

## File naming

```
YYYY-MM-DD-<short-description>.md
```

Example: `2026-03-23-api-gateway-design.md`
