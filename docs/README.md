# Docs

This directory contains general reference documentation, research notes, and material that doesn't fit neatly into architecture, processes, or automation.

## Contents

- Research and exploratory notes
- Meeting notes and decision logs
- Reference material
- Project-level context documents

## When to add something here

- You have reference material that supports multiple areas of work
- You want to capture research or exploration that informed decisions
- You're documenting context for future Claude sessions

## File naming

```
YYYY-MM-DD-<short-description>.md   (for dated notes)
<topic>.md                           (for reference docs)
```
