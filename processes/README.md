# Processes

This directory contains process documentation, runbooks, SOPs, and workflow definitions.

## Contents

- Runbooks for operational tasks
- Standard Operating Procedures (SOPs)
- Workflow definitions and checklists
- Onboarding guides

## When to add something here

- You're documenting a repeatable procedure
- You want to standardize how a task is performed
- You're creating a checklist or step-by-step guide for operational work

## File naming

```
<category>-<short-description>.md
```

Examples:
- `runbook-deploy-service.md`
- `sop-incident-response.md`
- `checklist-release.md`
